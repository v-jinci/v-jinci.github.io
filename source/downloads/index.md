## 这个区是干什么的

平时整理的一些文件放在这儿，方便在外面随时取：笔记、图片包、小工具、资料合集之类。
需要密码的话私信或者发邮件找我要。

## 大小与流量限制（先看这个，免得白传）

本站架在 GitHub Pages 上，所有文件都跟着代码仓库走，所以有几条硬限制：

| 项目 | 限制 | 说明 |
| --- | --- | --- |
| 单个文件 | **100 MB 是硬上限** | 超过就推不上去，会直接报错。实际建议 ≤ 50 MB |
| 整个站点 | 建议 ≤ 1 GB | GitHub 的软限制，超了会警告、可能被限流 |
| 每月流量 | 约 100 GB（软限制） | 个人博客几乎用不到；一个 50 MB 的文件被下 2000 次才会接近 |
| 文件类型 | 任意 | 但 .exe / .zip 有些浏览器会提示"可能有害"，属正常安全提示 |

**所以**：几十 MB 以内的小文件直接放这儿没问题；超过 50 MB 的（视频、大型安装包、整套素材）建议放网盘，这里只挂个链接，不占仓库体积。

## 关于密码

这一页的访问密码是**前端校验**：没输对密码看不到文件列表，也点不到下载链接。
它能挡住随手点进来的人，但**不能当保险箱**——静态网站的文件本身是公开的，懂技术的人绕过页面也能拿到地址。

真要保密的文件，请先打成带密码的压缩包（7z / zip 加密）再放上来，密码单独告诉我。
